# 💰 Controle Financeiro Pessoal

Aplicação web desenvolvida para auxiliar no controle de receitas e despesas pessoais de forma simples e intuitiva.

O projeto permite registrar transações financeiras, acompanhar o saldo disponível e visualizar o histórico de movimentações.

## 🚀 Funcionalidades

- Cadastro de receitas e despesas
- Categorização das transações
- Cálculo automático do saldo
- Total de receitas e despesas
- Histórico de movimentações
- Filtro por tipo de transação
- Exclusão de transações
- Armazenamento dos dados no navegador com LocalStorage
- Interface responsiva

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
